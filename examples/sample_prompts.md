# Example prompts by mode

## OS / Linux Lab
- "Write a bash script that counts how many .txt files are in a directory recursively."
- "My `chmod 755 script.sh` still gives permission denied when I run `./script.sh`. Why?"

## DBMS / Oracle SQL & PL-SQL
- "Write a PL/SQL trigger that logs every UPDATE on the `employees` table into `employee_audit`."
- "Explain the difference between a correlated and non-correlated subquery, with an example."

## Software Engineering Project
- "Draft the functional requirements section of an SRS for a library management system."
- "Give me a class diagram (as a Mermaid/PlantUML description) for an online food ordering system."

## Coding
- "Implement a binary search tree in Java with insert, search, and in-order traversal."

## Debug
- "This C program segfaults: [paste code]. What's wrong?"

## Exam (mark-aware)
- "Question: What is a deadlock? (2 marks)"
- "Question: Explain the four necessary conditions for deadlock with examples. (10 marks)"

## Viva
- "Generate viva questions for a DBMS mini-project that implements a hospital management system."

## Document (RAG)
Upload a PDF of your lab manual or lecture notes, enable "Use my documents",
then ask: "Summarize the normalization rules covered in chapter 3."
